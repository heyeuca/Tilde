> `~` — 홈, 순수한 텍스트, 그리고 딱 필요한 만큼만.

---

## Tilde란?

소프트웨어를 만드는 방식이 달라졌습니다. AI 기반 개발이 보편화되면서 코드를 직접 읽고 고치는 일이 훨씬 줄었습니다. 그래서 `.txt`나 `.md` 파일 하나를 잠깐 열어보려고 무거운 IDE를 켜는 건 과합니다.

Tilde는 바로 그 빈틈을 채웁니다. macOS를 위한 초경량 텍스트 에디터로, 단 하나의 아이디어를 중심으로 만들어졌습니다 — 파일을 열고, 읽고, 필요하면 한 줄 고치고, 닫는다. 프로젝트도, 워크스페이스도, 플러그인도, 터미널도, 사이드바도 없습니다.

목표는 더 작은 IDE가 아닙니다. 에디터가 사라지고 내용만 남는 것이 목표입니다.

## 핵심 가치

- **즉각적 (Instant)** — 파일을 더블클릭하면 거의 즉시 열립니다.
- **조용함 (Quiet)** — 인터페이스가 내용보다 더 눈에 띄지 않습니다.
- **네이티브 (Native)** — macOS 기본 앱처럼 동작합니다.
- **아름다움 (Beautiful)** — 텍스트를 읽는 것 자체가 즐거움입니다.
- **부담 없음 (Disposable)** — 설정하거나 관리할 것이 거의 없습니다.

## 이런 분들을 위해

Tilde는 평범한 텍스트 파일을 빠르게 읽거나 가볍게 고치고 싶은 사람을 위한 도구입니다:

- AI와 함께 일하며 코드 에디터에 머무는 시간이 줄어든 개발자
- Markdown 문서를 자주 읽는 사람
- 무거운 에디터를 켜지 않고 README, 메모, 설정 파일을 잠깐 확인하고 싶은 사람

Tilde는 IDE도, 프로젝트 워크스페이스도, 노트 데이터베이스도, Markdown 저작 도구도 **아닙니다**. Git 연동, 플러그인, 다중 파일 탐색이 필요하다면 Tilde는 의도적으로 맞지 않는 도구입니다.

## 기능

- 네이티브 macOS 문서 기반 앱 (파일 하나 → 창 하나)
- `.txt`, `.md`, `.markdown` 파일 열기 / 편집 / 저장
- 대부분의 UTF 기반 평문 파일(`.json`, `.yaml`, `.toml`, `.xml`, `.csv`, `.log`, `.env` 등)을 평문으로 열기
- 문법 기호는 그대로 보여주면서 가독성을 높이는 경량 Markdown 스타일링
- Reader 모드 (`⌘⇧R`) — Markdown 문서를 표·하이라이트된 코드 블록까지 완전히 렌더링해 읽기 전용으로 보여주는 뷰. `#fragment` 링크는 문서 안에서 이동하고 웹 링크는 브라우저로 열림. 옆에 있는 로컬 파일을 가리키는 링크와 이미지는 macOS가 파일 접근을 허용하는 범위에서 동작 — App Sandbox가 문서 옆 파일을 차단하면 이미지는 대체 텍스트가 표시되고 링크는 반응하지 않음. Safari의 Reader처럼 타이틀바에서 토글
- config 파일을 위한 조용한 문법 하이라이팅: `.json`·`.yaml`·`.toml`의 키만 색을 입히고 나머지는 그대로
- 표준 편집: 실행 취소/다시 실행, 잘라내기/복사/붙여넣기, 드래그 앤 드롭, 맞춤법 검사, 찾기 및 바꾸기
- 자동 줄 바꿈(기본 켜짐) 및 선택적 줄 번호 표시
- macOS 시맨틱 컬러를 활용한 라이트 / 다크 / 시스템 모드
- 빠른 실행과 유휴 시 거의 0에 가까운 리소스 사용량
- 완전한 macOS 통합: 다음으로 열기, 파일 연결, 최근 문서, 자동 저장, 버전, 전체 화면, 창 탭

### Markdown, 가볍게

Markdown 파일에는 은은한 시맨틱 스타일링을 적용합니다. 제목의 `#`는 그대로 보이면서 글자만 조금 더 크게 렌더링되고, `**굵게**`는 기호를 유지한 채 안쪽 텍스트를 굵게 표시할 수 있습니다. Markdown을 숨기는 것이 아니라 더 읽기 쉽게 만드는 것이 목적입니다.

스타일이 적용되는 요소: 제목, 굵게, 기울임, 취소선, 인라인 코드, 코드 블록, 인용구, 링크, 글머리 기호 목록, 번호 매기기 목록, 수평선.

## 키보드 단축키

Tilde는 macOS 관례를 따릅니다.

| 동작 | 단축키 |
| --- | --- |
| 새로 만들기 | `⌘N` |
| 열기 | `⌘O` |
| 저장 | `⌘S` |
| 다른 이름으로 저장 | `⌘⇧S` |
| 닫기 | `⌘W` |
| 찾기 | `⌘F` |
| 다음 찾기 | `⌘G` |
| 이전 찾기 | `⌘⇧G` |
| 찾기 및 바꾸기 | `⌥⌘F` |
| Reader | `⌘⇧R` |
| 환경설정 | `⌘,` |
| 글자 크게 | `⌘+` |
| 글자 작게 | `⌘-` |
| 글자 크기 초기화 | `⌘0` |

## 프라이버시

Tilde는 모든 문서를 로컬에서 처리합니다.

- 서버 업로드 없음
- 계정 및 로그인 없음
- 클라우드 저장소 없음
- AI 기능 없음
- 초기 릴리스에 분석(analytics) 없음

## 빌드

Tilde는 Swift, SwiftUI, AppKit으로 만들어졌습니다. SwiftUI를 주 기술로 사용하고, 성숙한 텍스트 엔진이 필요한 부분에서는 `NSTextView`를 감싸서 사용합니다.

요구 사항:

- macOS
- Xcode

빌드 및 실행:

```bash
open Tilde.xcodeproj
```

이후 Xcode에서 빌드 및 실행(`⌘R`)합니다.

## Non-Goals (하지 않는 것)

Tilde는 다시 완전한 IDE로 변질될 만한 요소는 의도적으로 배제합니다:

- 터미널, Git, 디버거, 빌드/실행, LSP, IntelliSense, 리팩터링, 프로젝트 탐색기
- 확장, 플러그인, 마켓플레이스
- 노트 데이터베이스, 태그, 백링크, 볼트, 위키, 동기화
- 계정, 댓글, 공유 워크스페이스, 실시간 협업
- AI 자동 완성, 채팅, 재작성, 에이전트

이런 결정의 배경이 되는 제품 철학 전체는 [docs/PRODUCT.md](docs/PRODUCT.md)에서 볼 수 있습니다.

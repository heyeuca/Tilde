# Tilde 1.4.0

A Format menu for Markdown, task-list boxes that copy as text, and fixes for links with parentheses and for Save As.

## New

- **Format menu for Markdown.** Bold (⌘B) and Italic (⌘I) wrap the selection in `**` / `*`, or take the markers off again. Add Link… (⌘K) turns the selection into `[text](url)`, using the URL on the clipboard if there is one. Typing `*`, `_`, `` ` ``, `~`, `[`, `(` or `"` over a selection wraps it instead of replacing it, so a second `*` makes it bold. Each command is one ⌘Z. Paste (⌘V) is unchanged. (#20)
- **Task lists copy as text.** Copying a task list from Reader as plain text gives `☐` / `☑︎` for each box, the way a bullet gives `•`. Rich-text copies keep the box images. (#47)

## Fixed

- Links whose URL contains parentheses, like `[Foo](https://en.wikipedia.org/wiki/Foo_(bar))`, and README badges like `[![CI](…)](…)` are styled as one link in the editor, and ⌘-click opens the full address. This was a known issue in 1.3.0. Escaped brackets in link text work too, and ⌘K escapes brackets in the text it links. (#38)
- Save As and Duplicate keep a file's extension, such as `.json` or `.sh`, instead of proposing `.txt`. The new file also keeps the original's permissions, so a copy of a private key stays readable only by you, and a copied script stays executable. (#39)

## Install

Already on Tilde 1.2.0 or later? Choose **Tilde ▸ Check for Updates…**. If you installed with Homebrew, run `brew upgrade --cask tilde`.

For a new install:

1. Download `Tilde-v1.4.0.dmg` below.
2. Open the DMG.
3. Drag Tilde to Applications.
4. Open a `.txt`, `.md`, or `.markdown` file with Tilde.

Requires macOS 14.0 or later.

## Notes

Known issue: files with no extension, like `id_ed25519`, or an extension macOS doesn't know, like `.pub`, still get `.txt` proposed on Save As and Duplicate. Their permissions are kept (#39).

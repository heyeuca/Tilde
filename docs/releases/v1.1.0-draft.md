# Tilde 1.1.0

Markdown files that open with YAML frontmatter — blog posts, docs pages, agent and skill files — now read the way they're meant to.

## New

- **Frontmatter in the editor.** A leading `---` … `---` block of `key: value` lines is recognized as metadata. Its fences are dimmed instead of drawn as rules, and the lines between them stay quiet and plain: `tags: [snake_case_tag]` no longer turns italic, and `- item` no longer becomes a list. (#5)
- **Frontmatter in Reader.** Reader shows the block as a quiet header at the top of the page. `title:` becomes the page title, the other keys follow as aligned rows of key and value, and a hairline separates the header from the body. After five rows the rest fold into "+N more", and long values are cut with a quiet "more" — click either to see the rest. Switching to Reader still opens at the place you were reading. (#11)

Only a block that reads as metadata counts. A document that opens with a `---` rule and uses more rules as chapter breaks renders exactly as before.

## Install

1. Download `Tilde-v1.1.0.dmg` below.
2. Open the DMG.
3. Drag Tilde to Applications.
4. Open a `.txt`, `.md`, or `.markdown` file with Tilde.

Requires macOS 14.0 or later.

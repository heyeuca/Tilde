# Tilde 1.5.0

Untitled windows that come back after you quit, Reader that hands you back to the place you were reading, and pinch to change the font size.

## New

- **Untitled windows come back after you quit.** ⌘Q no longer asks whether to review untitled documents. The next launch brings each untitled window back with its text, still untitled and still edited, so ⌘S opens the save panel and ⌘W still asks whether to save. Blank windows don't come back. If you have changed "Close windows when quitting an application" in System Settings, Tilde follows that choice. (#44)
- **Leaving Reader returns to where you were reading.** However you leave Reader (Esc, ⌘⇧R, or the title-bar toggle), the editor scrolls to the text that was at the top of Reader, give or take a few lines. The caret and selection stay where they were, and if you didn't scroll in Reader the editor doesn't move. (#13)
- **Pinch to change the font size.** Pinch out on the trackpad to make text bigger and pinch in to make it smaller, in the editor and in Reader. It changes the same size as ⌘+ / ⌘- / ⌘0 and the Settings slider, in whole points from 9 to 36. (#4)

## Fixed

- Undoing Bold, Italic or Add Link restores the selection you had, and redo restores the selection after the edit. Before, undo left only a caret. (#42)
- Undoing Tab or ⇧Tab on selected lines restores the exact selection, and redo keeps the lines selected. (#59)
- Pressing ⌘B or ⌘I again inside an empty pair of markers removes the pair instead of nesting another one. (#43)

## Install

Already on Tilde 1.2.0 or later? Choose **Tilde ▸ Check for Updates…**. If you installed with Homebrew, run `brew upgrade --cask tilde`.

For a new install:

1. Download `Tilde-v1.5.0.dmg` below.
2. Open the DMG.
3. Drag Tilde to Applications.
4. Open a `.txt`, `.md`, or `.markdown` file with Tilde.

Requires macOS 14.0 or later.

## Notes

Known issue: files with no extension, like `id_ed25519`, or an extension macOS doesn't know, like `.pub`, still get `.txt` proposed on Save As and Duplicate. Their permissions are kept (#39).

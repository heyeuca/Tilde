# Tilde 1.5.1

A shortcut that opens a blank document from any app, and fixes for Reader and for files another app changes.

## New

- **Quick Document.** Record a shortcut in **Settings ▸ Keyboard Shortcuts**, then press it in any app to bring up a blank Tilde document. If a blank untitled window is already open, it comes forward instead of a new one. There is no shortcut until you record one, and it works only while Tilde is open. (#62)

## Fixed

- Esc leaves Reader however you entered it. Before, it did nothing after **View ▸ Show Reader** or the title-bar toggle, or after you closed the find bar. (#66)
- Unsaved edits are kept when another app writes the open file through macOS file coordination. Before, the window switched to the other app's version without asking, and undo couldn't bring the edits back. Now Tilde asks which version to keep when it next saves, as it already did for other kinds of writes. (#32)

## Install

Already on Tilde 1.2.0 or later? Choose **Tilde ▸ Check for Updates…**. If you installed with Homebrew, run `brew upgrade --cask tilde`.

For a new install:

1. Download `Tilde-v1.5.1.dmg` below.
2. Open the DMG.
3. Drag Tilde to Applications.
4. Open a `.txt`, `.md`, or `.markdown` file with Tilde.

Requires macOS 14.0 or later.

## Notes

Known issue: files with no extension, like `id_ed25519`, or an extension macOS doesn't know, like `.pub`, still get `.txt` proposed on Save As and Duplicate. Their permissions are kept (#39).
